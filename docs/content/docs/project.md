Hammerwright is open source under MIT OR Apache-2.0, part of Kovir Labs. The
repository is on GitHub,
[github.com/kovirlabs/wrought](https://github.com/kovirlabs/wrought).

- **Contributing:** how work flows, the checks to run, the project rules
  (feature discipline, the statement catalogue, the decision log) and the
  issue labels, including `good first issue` per crate:
  [`CONTRIBUTING.md`](https://github.com/kovirlabs/wrought/blob/main/CONTRIBUTING.md).
- **Governance:** a single project lead for now, a small maintainer team
  once there are regular contributors, and how that change happens:
  [`GOVERNANCE.md`](https://github.com/kovirlabs/wrought/blob/main/GOVERNANCE.md).
- **Security:** report problems privately, never in a public issue:
  [`SECURITY.md`](https://github.com/kovirlabs/wrought/blob/main/SECURITY.md).
  Release binaries are signed; see [releases](/docs/releases/).
- **How it works:** the [architecture guide](/docs/architecture/), and the
  reasons behind each design choice in
  [`DECISIONS.md`](https://github.com/kovirlabs/wrought/blob/main/DECISIONS.md).
- **What changed:**
  [`CHANGELOG.md`](https://github.com/kovirlabs/wrought/blob/main/CHANGELOG.md).
