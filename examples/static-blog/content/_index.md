Welcome. This site is plain Markdown in a `content/` folder, rendered by
[Hammerwright](https://github.com/kovirlabs/wrought) into static HTML. There is no
database and nothing to run in production but a web server.

Edit `content/_index.md` to change this text, or add a file to `content/blog/`
to publish a post.
