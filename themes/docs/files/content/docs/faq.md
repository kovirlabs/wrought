## Does it need JavaScript?

No. Pages are plain HTML; scripts only add comfort where a browser runs
them.

## Can I change the colours?

Yes: set the design tokens under `[ui.tokens]` in `site.toml`.

## Where do I report a problem?

Open an issue in the project's repository with what you did, what you
expected and what happened.
