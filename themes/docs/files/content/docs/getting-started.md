## Install

Download the release for your system and put it on your `PATH`:

```sh
tar -xzf tool-linux-x86_64.tar.gz
sudo mv tool /usr/local/bin/
```

## Create a project

```sh
tool new my-project
cd my-project
tool run
```

Open the address it prints. Every save reloads the page.
